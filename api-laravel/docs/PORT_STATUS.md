## Test gates

1. `vendor/bin/pint --dirty` — style.
2. `vendor/bin/phpstan` (larastan) — static analysis (report-only until findings clear).
3. `vendor/bin/pest` — the full suite.
4. `php artisan inventory:check` — inventory artifacts fresh, ledger complete,
   milestone scopes meet the gate (`--milestone=m1` for the scope above).
5. Contract suite — `PAO_DISABLE=1 DB_DATABASE=<disposable> ./vendor/bin/pest tests/Contract`
   replays the captured Rails goldens.
